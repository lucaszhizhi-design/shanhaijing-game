# 山海经守护神兽测试游戏 — 设计规格

## Context

家长将在小学三年级课堂做AI主题分享课（15-20分钟），用这个网页游戏作为互动展示，让孩子们体验"AI为你生成专属题目并匹配守护神兽"的过程。核心目标：不说教、有趣味性、体现AI能力、适合8-9岁认知水平。

## 游戏流程（5个阶段）

1. **开场页** — 大标题"测测你的山海经守护神兽"，古风炫酷背景动画（星空/粒子），输入姓名框
2. **AI生成动画页** — 输入姓名后，显示"AI正在为[姓名]生成专属题目…"的动画效果（打字机文字+数据流粒子），约3秒后过渡到答题页
3. **答题页（5题）** — 每题3选项（第5题2选项），逐题出现，答完有轻微反馈动效
4. **匹配动画页** — 5题答完后，"AI正在匹配你的守护神兽…"，粒子汇聚光效动画，约3秒
5. **结果页** — 神兽亮相短视频 → 高清图片卡片（名称+性格标签+守护寄语），底部"再测一次"+"看看其他神兽"按钮

## 性格维度 × 神兽体系

4维度 × 2只神兽 = 8只：

| 维度 | 神兽1 | 神兽2 | 性格关键词 |
|------|-------|-------|-----------|
| 勇气 | 麒麟 | 狻猊 | 勇敢、无畏、敢于挑战 |
| 智慧 | 白泽 | 烛龙 | 聪明、好学、善于思考 |
| 创意 | 青鸟 | 九尾狐 | 想象力、灵感、天马行空 |
| 友善 | 当康 | 鹿蜀 | 温暖、善良、乐于助人 |

## 题目设计框架

| 题号 | 目标维度 | 选项数 | 设计 |
|------|----------|--------|------|
| 1 | 勇气 | 3 | 主选项+勇气3分，次选项给其他维度少量加分 |
| 2 | 智慧 | 3 | 同上结构 |
| 3 | 创意 | 3 | 同上结构 |
| 4 | 友善 | 3 | 同上结构 |
| 5 | 综合细分 | 2 | 在已确定的主维度内二选一，直接对应2只神兽 |

题目风格：趣味场景式提问（如"你在森林里遇到一只巨大怪兽挡路，你会？"），不直接问性格。

计分示例（第1题）：
- A. 拿起木棍勇敢冲上前 → +勇气3
- B. 仔细观察找弱点 → +智慧2, +勇气1
- C. 叫上好朋友一起想办法 → +友善2, +创意1

## 匹配算法

1. 累加前4题各维度得分
2. 取最高分维度为主维度
3. 第5题的2个选项分别对应主维度的2只神兽
4. 若最高分维度有并列，取第5题选项中偏向的维度

## 结果页内容

每只神兽卡片包含：
- 神兽名称（大字+光效）
- 神兽形象短视频（3-5秒亮相）+ 静态高清图片
- 3个性格标签词
- 个性化守护寄语（关联孩子性格与神兽特征）
- "再测一次"按钮 + "看看其他神兽"按钮（浏览8只全图鉴）

## 视觉风格

炫酷游戏风：鲜亮色彩、光效/粒子动画、神兽形象用AI生成（自带光效氛围），HTML端加少量CSS辅助动画。大屏投影优化：大字体、高对比度、视觉冲击优先。

## 技术架构

- **纯前端**：index.html 内嵌 CSS + JS，无需构建工具和服务器
- **题库**：JS内置JSON数组，多组题目随机抽取避免重复
- **匹配算法**：维度得分累加 → 最高维度 → 第5题细分
- **动画效果**：CSS动画 + Canvas粒子特效（开场背景、AI生成动画、匹配动画）
- **神兽素材**：AI生成的图片(PNG) + 短视频(MP4)，放入assets目录引用
- **无外部依赖**：不调用API、不联网、课堂环境最稳定
- **播放兼容**：视频用HTML5 `<video>` 标签，备选静态图兜底

## 验证方式

1. 本地浏览器打开 index.html，完整走一遍游戏流程（输入姓名→答题→匹配→看结果）
2. 验证匹配逻辑：分别选择不同维度倾向的答案组合，确认8只神兽都能被匹配到
3. 验证"再测一次"能重新开始、"看看其他神兽"能浏览全部8只
4. 在投影仪环境下测试字体大小和颜色对比度是否清晰可读
5. 确认视频播放正常，无视频时静态图兜底也OK
