# 山海经神兽素材生成提示词

## 通用风格要求

所有素材统一风格：**中国神话×炫酷游戏风**，暗色背景、光效粒子、游戏级质感。
- 每只神兽有专属配色（与游戏中SVG占位图一致）
- 深色氛围背景（#0d0d2b 深蓝黑），自带光晕和环境光效
- 神兽姿态威猛或灵动，画面有冲击力
- 适合小学三年级观看——避免恐怖血腥，保持炫酷但不吓人

| 麒麟 | qilin.png | qilin.mp4 |

| 白泽 | baize.png | baize.mp4 |

| 青鸟 | qingniao.png | qingniao.mp4 |

| 当康 | dangkang.png | dangkang.mp4 |
| 鹿蜀 | lushu.png | lushu.mp4 |

放入素材后，需修改 `index.html` 中 BEASTS 数组的 image 字段从 `.svg` 改为 `.png`（8处修改）。

图片尺寸建议：400×400px（正方形），视频建议 3-5秒、400×400px、MP4格式。
